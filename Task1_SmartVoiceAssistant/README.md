# OASIS INFOBYTE – Python Programming Internship

## Task 1: Smart Voice Assistant

### Project Description
Smart Voice Assistant is a Python-based application that responds to voice commands and performs simple tasks using speech recognition and text-to-speech technology.

### Features
- Responds to greetings
- Tells the current time and date
- Opens Google, YouTube, and Gmail
- Searches topics on Google
- Speaks responses aloud
- Supports voice commands to exit

### Technologies Used
- Python 3
- SpeechRecognition
- pyttsx3
- PyAudio

### Installation

Install the required libraries using:

```bash
python -m pip install SpeechRecognition pyttsx3 pyaudio
```

### How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. Allow microphone access and speak your command.

### Example Voice Commands
- Hello
- How are you?
- What is the time?
- What is the date?
- Open Google
- Open YouTube
- Open Gmail
- Search Python tutorials
- Exit
