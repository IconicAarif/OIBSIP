# OASIS INFOBYTE – Python Programming Internship

## Task 3: Secure Password Maker

### Project Description
Secure Password Maker is a Python application that generates random passwords based on the user's selected character types and desired password length.

### Features
- Generates random passwords
- Supports uppercase and lowercase letters
- Includes numbers and symbols
- Allows password length selection
- Validates user input
- Uses Python's `secrets` module for secure random generation

### Technologies Used
- Python 3
- `secrets` module
- `string` module
- Functions and conditional statements

### How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Enter the password length.
6. Select the character types using `y` or `n`.
