# OASIS INFOBYTE – Python Programming Internship

## Task 2: Health Metrics Calculator (BMI Calculator)

### Project Description
The Health Metrics Calculator is a Python application that calculates Body Mass Index (BMI) using a person's weight and height.

### Features
- Accepts weight in kilograms
- Accepts height in centimeters
- Calculates BMI
- Displays the BMI value and category
- Validates incorrect and non-positive inputs
- Displays a health information disclaimer

### Technologies Used
- Python 3
- Functions
- Conditional statements
- Exception handling

### How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Enter your weight in kilograms and height in centimeters.
